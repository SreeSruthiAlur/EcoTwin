# EcoTwin
Project 1 of Infotact DS &amp; ML Internship
 
## Dataset: Bologna Small Scenario 
This project uses the **Bologna_small** scenario from the COLOMBO project located in `assets/bologna_small/`. 
- **Road Network:** Real-world roundabout and intersection layout in Bologna, Italy (`.net.xml`). 
- **Traffic Demand:** Calibrated vehicle flow and route distributions (`.rou.xml`). 
- **Configuration:** Pre-configured SUMO entry point (`.sumocfg`). 
- **Suitability:** Built specifically for traffic-light control research, providing signal programs ready for RL agents.
